## 1. 起因

ILB 回了 `D:\文档\1\DSH\ILB\docs\答复-逻辑与界面联动.md`：申请通过，接口 **v1.1 → v1.2**，新增四样东西。

| ILB 给的 | 形状 | 说明 |
|---|---|---|
| `ui` | 返回值**顶层**（不是 `extra.ui`） | 一次性指令，带了才生效 |
| `callAsync` | `api.callAsync(name, args, opts)` → Promise | 逻辑可能要跑几秒，界面不能假死 |
| `durationMs` | 数字 | 这条逻辑跑了多久 |
| `caps` 里的 `'ui'` | 能力位 | 老版本不会假装支持 |

同时 ILB 明确了几条我们得照着做的约束：

- **不做 `confirm`**：ILB 没有可挂起的运行时，等不了用户点按钮。
- **不接受 HTML / CSS / 脚本**：`ui` 里只能有数据。
- **页面不存在不报错**，只提示。
- **`seq` 单调递增**，客户端只在变大时执行一次（刷新后 ILB 会重放）。
- 消息触发路径**只收集不执行**（AI 说话时不会偷偷翻你的界面）。

## 2. 做了什么

### 2.1 接口层（`src/api.js`）

| 函数 | 作用 |
|---|---|
| `hasCallAsync()` | 有没有 `api.callAsync` |
| `callLogicAsync(name, args, opts)` | 有 `callAsync` 走异步，没有就退回同步 `call`（同一个 Promise 形状） |
| `uiCommandOf(res)` | 取界面指令：**必须先有 `caps.includes('ui')`**，再要求 `ui.v === 1`；否则一律 `null` |
| `extraList(extra)` | 把 `string[]` / 字符串 / 旧的对象写法统一成数组 |
| `hasCap('ui')` | 状态行与门禁共用 |

### 2.2 交互层（`src/panel.js`）

**点击动作变成异步的**，并加了防叠加：

```
点按钮 → 立刻画「执行中…（抽卡）」→ await callAsync → 画结果
```

`state.busy` 挡的是“同一时刻的第二次 call”，避免手快连点时界面来回跳。

**消费界面指令**（`applyUiCommand`），顺序固定：

1. `seq` 去重：按**逻辑名**记账（`state.uiSeq[logicName]`），只有变大才执行。
2. `toast` → 顶替底部回执（截 80 字）。
3. `page` → 切页 + 页面 chip 闪一下；找不到页就只把提示挂到回执里，不报错。
4. `select` → 记下来，等这一轮画完再滚过去。
5. `ask` → 归一化成 `{title, text, ok}`。

`applyUiFocus` 在 `render()` **之后**跑（那时格子节点才存在）：

- 选中的控件不在当前页 → 先翻到它所在的页，再 `scrollIntoView({block:'nearest'})`。
- 格子加 `is-picked` 类 → CSS 亮一圈。

**新 DOM**：`.dshui-ask` 提示卡（标题 / 正文 / 「知道了」），`hidden` 默认开，不占地方。

**状态行**：能力位里有 `ui` 时，末尾多一个 `· ui`，一眼看出通道通没通。

**格子节点**：`dataset.cellId`，`select` 才有东西可找。

### 2.3 样式（`style.css`）

- `.dshui-cell.is-picked`：2px 强调色描边 + 两轮 1.1s 呼吸动画（`prefers-reduced-motion` 下由既有规则关掉）。
- `.dshui-ask`：淡蓝底、圆角、贴正文底部；`.dshui-ask-text` 用次要色。

## 5. 手动验收

1. 确认 ILB ≥ v1.2、状态行末尾有 `· ui`。
2. 在 ILB 里给某条逻辑末尾加 `ui: { v:1, seq:1, toast:'测试' }`，点对应按钮 → 回执被顶替。
3. 把 `toast` 换成 `page:'<某个页面 id>'` → 界面翻页，chip 闪一下。
4. 加 `select:'<某个控件 id>'` 且该控件在另一页 → 自动翻页并亮一圈。
5. 加 `ask:{title,text,ok}` → 底部出现卡片；**同时还能继续点别的按钮**（不阻塞）。
6. 把 `page` 改成不存在的 id → 只提示「没有这一页」，不切页、不报错。
7. 同一个 `seq` 再触发一次 → 界面不再动（回执正常更新）。

## 6. 已知边界

- **没有 confirm**：`ask` 只是提示卡，不是模态；用户不点它就一直在（直到下次 `ask` 覆盖或点「知道了」）。
- `ask` 只保留**一张**：后一条覆盖前一条，没有队列。
- `select` 只高亮**视觉**，不移动键盘焦点（读屏用户靠回执那句播报）。
- `toast` 截 80 字，长了会掉字。
- `seq` 记在内存里：刷新页面后清零，所以刷新后的第一次调用一定会生效（这是想要的行为）。
- `busy` 只挡 `call`，不挡 `set/add/toggle`（本地写变量很快，没必要挡）。
- 异步期间按钮**仍可点**：本体没有禁用态，靠 `busy` 吞掉重复 call。
- 逻辑名重名时 `seq` 会串台（按名字记账）；用 `id` 调用的场景不在 UI 这边，暂不处理。
