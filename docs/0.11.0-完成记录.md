# 0.11.0 完成记录 · 布局库可视化管理

## 需求

User said (m05828): "那么就开始执行布局可视化管理的开发吧"

承接 0.10.0 交付时的建议：布局库原来只有一个下拉，能切换、能存，但改名、复制、调顺序、删除都得去翻浏览器存储；「清除失效」还是正文工具栏里的一个按钮，和"管理布局"这件事分散在两处。

## 做了什么

工具栏上原本的「库」按钮（此前只是占位）现在把正文整块换成**布局库屏**：

| 区域 | 内容 |
|---|---|
| 顶部 | `布局库` + 条数 + 「＋ 新建」+「返回界面」 |
| 列表每条 | 标题（点一下就用它）、徽标（当前 / 全局 / 角色卡 / 失效）、`N 页 · M 控件 · 最后修改日期`、操作按钮条 |
| 操作 | 应用 · 改名 · 复制 · ↑ · ↓ · 删除 |
| 底栏 | 保留，显示每次操作的结果（已改名 / 已复制 / 已删除 / 再点一次确认） |

- **改名**：标题行就地变输入框，回车或「保存」生效，Esc 取消；空标题拒绝并提示。
- **复制**：立刻多一条「… 副本」，`id` 重新分配，原件不动；复制出来的条目**不会**自动切过去（和编辑器里的「复制成新布局」不同，那个会切）。
- **↑ ↓**：在存储数组里原位移动后整表写回，`updatedAt` 不变；到头的方向按钮置灰。
- **删除**：两段式。第一次点按钮变红并改成「确认删除」，底栏提示「再点一次才会删掉」；第二次才真删。删掉的正是当前选中项时，顺手清掉选中，界面退回示例布局。
- **＋ 新建**：生成 `{ schema, title: '新布局', grid: {cols:4,rows:2}, cells:[ 一个标题格 ] }`，作用域跟随当前（有角色卡就存角色卡），存完直接进编辑器。
- **应用**：点标题或「应用」→ 关掉库屏、切到该布局、底栏写「布局：<标题>」。

## 三屏互斥

面板里现在有三块"占满整块地方"的屏：正文、使用说明（`?`）、布局库（`库`）。新增 `sheetMode()` 做唯一出口：

```
function sheetMode() {
  if (state.help === true) return 'help';
  if (state.lib === true) return 'lib';
  return '';
}
```

`applyHelpUi()` 按它决定谁可见；打开说明会关掉库，打开库会关掉说明。`render()` 在库/说明屏下跳过 `renderBody()`，但仍然调用 `renderFoot()`——否则改名、删除的结果没地方显示（这是开发中实测抓到的第一个 bug）。

## 踩到的坑

1. **`renderFoot()` 没被调用**：`render()` 原本是 `if (state.help !== true) renderBody()`，库屏下两条都不走，底栏停在初始状态，所有操作都"没反应"。修法：`else renderFoot()`。
2. **函数重名被静默覆盖**：我新写的 `duplicateLayout(entry)` 和编辑器里 0.9.0 就有的 `duplicateLayout()`（草稿成新布局）同名，函数声明提升后**后定义的那个生效**，点「复制」复制的是当前示例布局，不是列表里那一条（测试里表现为"副本标题是『示例面板 副本』"）。改名成 `duplicateLibraryEntry` 才对。
3. **「返回」按钮重名**：库屏的「返回」和说明屏的「返回」文本相同，测试里按文本找按钮找到了错误的那一个。库屏改成「返回界面」。
4. **PowerShell 又改坏了中文**：用 `(Get-Content -Raw) -replace ... | Set-Content` 修探针脚本，整个文件的中文变 GBK 乱码并语法报错。教训同 D-U02 时代：**中文文件只能用 read/edit 工具改**。

## 手动验收（6 步）

1. 刷新页面（Ctrl+F5），标题栏版本应是 `v0.11.0`。
2. 点工具栏「库」：能看到已存布局，每条有页数/控件数/日期。
3. 点某条「改名」→ 改个字 → 回车：列表和下拉都变了。
4. 点「复制」：多一条「… 副本」，点它的名字立刻切过去。
5. 点「删除」一次（按钮变红）→ 点别处 → 再点一次「确认删除」：条目消失。
6. 点「＋ 新建」：得到一个只有标题的空白布局，直接进编辑器。

## 已知边界

- 库屏里看不到当前界面长什么样，要点「返回界面」。
- 删除的「举手」状态不会自动收回（点别处仍在），靠底栏那句提示兜底。
- 排序是全局一条列表：全局布局和各角色卡布局混在一起排，不分组。
- 库屏仍受 `D-U15` 约束：别的角色卡的条目只显示、不提供删除。
- 「＋ 新建」没有模板可选，只有标题格一个控件。
- 改名不校验重名：两个布局可以同名，只能靠日期和内容区分。
