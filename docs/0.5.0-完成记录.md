## 已知边界

- 内嵌帮助是精简版，与 `docs/使用说明.md` 手工同步。
- 帮助正文不支持链接/图片（避免 innerHTML，只用纯文本节点）。
- 编辑态面板较矮时，预览网格按 `minCellHeight` 压缩行高，格内文字可能被截；把拖动条往下拖、或调小行数即可（预览区本身可滚动）。
