# 0.6.0 完成记录 —— 编辑全屏 + 预览按钮

## 需求

编辑和预览不再挤在同一个抽屉里共用空间。改法：

- **编辑态**：抽屉正文整个让给编辑器（表单或 JSON），没有网格挤在下面。
- **预览**：不在抽屉里，而是铺满整个视口的浮层，看起来就像真的把界面铺在页面上。

## 交互：一个预览按钮，两种用法

编辑态工具栏里多一个「预览」按钮：

| 操作 | 进入 | 退出 |
| --- | --- | --- |
| **按住**（≥220ms） | 临时预览（"临时预览 · 松手返回"） | 松手即回编辑 |
| **点一下** | 交互预览（"交互预览 · 点按钮会真的改变量"） | 再点按钮 / 浮层「返回编辑」/ Esc |

长按松手后浏览器补发的那个 `click` 会被 `peekArmed` 标记吃掉，避免顺手把界面锁进交互态。

## 预览浮层

- 铺满视口：`position:fixed` + `100vw` / `100dvh`（`dvh` 兜底手机地址栏伸缩）。
- 只放一张实时网格 + 一条状态栏；抽屉自己的状态行/工具栏/底栏在预览时都不出现。
- **挂载位置**：浮层挂在 `.dshui-root` 上，不是 panel 里面 —— panel 有 `backdrop-filter: blur(6px)`（会变成 `position:fixed` 的包含块）和 `overflow:hidden`，挂里面会被裁回 360px 抽屉。这是本轮实机验证抓到的真 bug。

## 已知边界

- 进交互预览后工具栏被浮层盖住，工具栏上那个按钮此时不可点；退出靠浮层自带的「返回编辑」或 Esc。`previewBtn` 的文案切换（结束预览）在预览中看不到，保留是为了浮层若非全屏时仍然正确。
- 退出预览后 `.dshui-preview-grid` 里会留着上一次的格子（浮层已 `display:none`，不可见）。下次进入会重画，无副作用。
- 长按阈值 220ms 是经验值，未做可配置。
