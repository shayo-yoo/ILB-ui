# 0.8.0 完成记录 —— 预览回到抽屉里

## 需求（用户原话）

> 「或许是我没表示清楚，全屏预览不是指的真的 铺满屏幕，而是在 ILBUI 的窗口上将 UI 和编辑器分离，但还是在 UI 中，请你再次修改。」

0.6.0 把预览做成了 `position: fixed` 铺满视口的一层，方向理解错了。这次要的是：**在抽屉内部**把「界面（网格）」和「编辑器」分开——两者不共用空间，但都还在 ILBUI 的窗口里。

## 最终形态

| 状态 | 抽屉正文那块地方放什么 | 面板外壳 |
| --- | --- | --- |
| 浏览（默认） | 网格 + 变量板 + 页签 + 工具 | 标题栏 / 状态行 / 工具栏 / 底栏 |
| 编辑 | 整块编辑器（表单或 JSON） | 同上 |
| 预览（长按或点按） | 整块实时网格 + 一条预览栏 | 同上（工具栏、状态行、底栏都还在） |

- 预览栏：左边一行小字「交互预览 · 点按钮会真的改变量」/「临时预览 · 松手返回」，右边「返回编辑」按钮。
- 长按 ≥220ms = 临时预览，松手即回编辑器；点一下 = 交互预览，栏里的按钮或 `Esc` 退出。
- 预览时仍能切布局下拉、看底部动作回执——这是和 0.6.0 那版最大的差别。

## 手动验收

1. 点右侧把手打开抽屉 → 点标题栏 `编辑`：正文只剩编辑器，没有网格。
2. 点编辑器底部 `预览`：正文换成网格，标题栏、状态行、布局下拉、底栏回执都还在。
3. 在预览里点 `金钱 +1`：数字变化，底栏出现回执。
4. 点预览栏 `返回编辑`：回到编辑器；再点 `预览` 后按 `Esc` 也能回。
5. 按住 `预览` 一秒钟：出现「临时预览」，松手自动回编辑器，且不会顺手锁进交互态。
6. 窄窗口（≤640px）重复 2–4：按钮变 44px 高，预览仍不超出抽屉。

## 已知边界

- 预览看到的宽度就是抽屉宽度，看不出「界面在超宽屏上被拉伸」的效果——这是「不打断叙事」换来的。
- 预览栏里没有布局下拉，切布局仍用上面的工具栏（预览时工具栏还在，可以用）。
- 退出预览后 `.dshui-preview-grid` 里留着上次的格子（层已 `hidden`，不可见），下次进入重画。
- 6 列 × 最小格宽 50px 的布局在 360px 抽屉里会横向溢出几像素（`.dshui-grid` 的既有行为，预览同样继承）。
- `dshui.ui.v1` 里的 `editorHeight` 字段自 0.6.0 起已不再使用，保留旧键不读、不迁移。
