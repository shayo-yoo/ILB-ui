> 那么折叠方案就按你推荐的B方案来执行。
> 同时在追加一条，为控件和布局添加复制等方便复用的功能，有时候需要根据现有的控件进行修改，比如要修改出一个UI的２.０版本。

即：① 页面切换 + 变量总览默认折叠（B 方案：收成细 chip，点开是浮层）；② 控件/页面/布局的复制；③ 联动能力只写申请文档，不动代码。

## 二、折叠（B 方案）

| 之前 | 现在 |
| --- | --- |
| `变量 · N` 一整块常驻，占 132px 上限 | 一条 `变量 · 4 ▾` chip，默认收起 |
| 多页时页签整行常驻 | 一条 `页面 · 主界面 ▾` chip，只有一页时干脆不出现 |
| — | 点开是**绝对定位浮层**，不参与布局流 |

- 结构（`src/panel.js:186-205`）：`.dshui-meta` 里放 `pageChip` / `varChip` / `pagePop` / `varPop`；`pagesBox`、`varsBox` 移进各自的浮层，`body.append(note, metaRow, gridBox, tools, editor)`。
- 渲染 `renderMeta(plan, p, vars)`：只改 `textContent` 与 `hidden`，不重建节点，所以点开/收起不闪。
- 交互：
  - 两条 chip 互斥（同时开会互相盖住），开合状态写进 `dshui.ui.v1` 的 `pagesOpen` / `varsOpen`；
  - 点浮层外面收起：用 `pointerdown` 记账（`pressInMeta`），因为 `setPage`/`bump` 会立刻重画，等 `click` 冒泡到 `document` 时目标节点已经被摘掉，`contains()` 会误判成"外面"；
  - Esc 层级：预览 → 浮层 → 抽屉，三下依次退；
  - 动作 `open` 切页后 chip 闪 700ms（`.is-flash`），否则界面"自己翻页"看起来像点错了；
  - `setPage` 选完自动收起浮层。
- 监听器都具名（`onMetaPointerDown` / `onDocClick`），`destroy()` 里成对 `removeEventListener`，不留悬挂监听。

省下的高度（390×844 实测，示例布局）：

| | 折叠前 | 折叠后 |
| --- | --- | --- |
| 变量区高度 | 96px（含标题行） | 28px（chip 一行） |
| 页面行 | 36px | 与变量同一行 |
| 网格起点 y | 336 | 240 |

浮层展开时网格起点仍是 240（`delta: 0`），即**展开浮层不会把下面的格子顶下去**。

## 三、复制三件套

| 入口 | 位置 | 行为 |
| --- | --- | --- |
| ⧉ | 表单每个控件行（↑ ↓ ⧉ 删） | 复制该控件插到下一行；id 自动让重（`gold` → `gold-2`）；区域自动下移一行并夹在网格内；复制后选中副本 |
| 复制页 | 表单「页面」行（＋ 页面 / 复制页 / 删除页） | 复制整页（含全部控件），页 id 与页内控件 id 全部重新编号，标题加「副本」，插到当前页后面并切过去 |
| 复制成新布局 | 编辑器动作条 | 校验当前草稿 → 深拷贝 → 清空 id（否则会覆盖原件）→ 标题加「副本」→ 存进布局库并切过去，原件不动 |

- 深拷贝用 `cloneJson()`（JSON 往返）——布局是纯 JSON，没有函数或循环引用。
- 让重签名 `freeId(used, base, fallback)`：`base` → `base-2` → `base-3` …
- 「复制成新布局」先跑 `validateLayout`，有错就只显示校验结果、不落盘；角色卡作用域但当前没有角色卡时给 warn 并中止。

## 六、手动验收

1. Ctrl+F5 刷新，面板版本应为 **v0.9.0**。
2. 浏览态：变量与页面各占一条细 chip，网格上方只有一行；点「变量 · 4 ▾」展开，下面的格子**不动**。
3. 再点一次 chip 收起；点浮层外面也收起；按 Esc 先收浮层、再按关抽屉。
4. 多页布局：点「页面 · …」，选另一页 → 浮层收起、chip 改名；点一个带 `open` 动作的按钮 → chip 闪一下。
5. 编辑态：控件行多一个 ⧉；点它 → 多一个控件、自动往下挪、选中副本。
6. 「复制页」→ 页数 +1、标题带副本；「复制成新布局」→ 底部提示「已复制为…（原件没动）」，布局下拉切到副本。

## 七、已知边界

- 变量浮层的 `max-height: min(46vh, 320px)`，变量特别多时要在浮层里滚动。
- 折叠状态记在 `dshui.ui.v1`，是**全局**偏好，不按布局分别记。
- 「复制成新布局」复制的是**当前草稿**（表单/JSON 里的内容）；有校验错误时拒绝复制。
- 控件副本默认下移一行，可能与其他控件重叠（校验只警告）；复制后需要自己调区域。
- 复制页时页内 `onClick` 里指向 `page` 的跳转目标保持原样（指向原件页的 id），不会自动改写到副本页。
