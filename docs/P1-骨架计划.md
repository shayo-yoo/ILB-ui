# P1 骨架计划（可跑通）

> 目标：一个能装进 SillyTavern 的最小扩展——右下角浮窗、可开可关的抽屉、**三态探针**（ILB 未加载 / 版本不符 / 正常）、**事件驱动的变量板**、刷新后记住开关。
> 本阶段**不**做：编辑器、布局库 UI、字符作用域、点击调逻辑（`call` 接口已封装，P2 才接按钮）。

## P1 支持的声明子集（其余给校验器报“P2 再做”，不要静默）

```jsonc
{
  "schema": "dshui/1",
  "id": "sample", "title": "示例面板",
  "grid": { "cols": 6, "rows": 4, "gap": 8, "padding": 10 },
  "cells": [
    { "id": "gold", "kind": "stat", "label": "金币", "var": "金币",
      "area": [0, 0, 2, 1], "suffix": " G", "onClick": { "kind": "add", "var": "金币", "by": 1 } },
    { "id": "hp", "kind": "stat", "label": "生命", "var": "生命",
      "area": [2, 0, 2, 1],
      "when": [{ "var": "生命", "op": ">", "value": 0 }],
      "onClick": { "kind": "add", "var": "生命", "by": -1 } },
    { "id": "hint", "kind": "text", "text": "点金币 +1，点生命 -1", "area": [0, 1, 6, 1] },
    { "id": "drink", "kind": "button", "label": "喝药水", "area": [0, 2, 3, 1],
      "onClick": { "kind": "add", "var": "生命", "by": -1 } }
  ]
}
```

**P1 只认三种控件**：`stat`（绑定变量）、`text`（字面量）、`button`（label + onClick）。
`bar/number/list/toggle` 在校验器里报 warning「P2 支持」，渲染时降级成 `stat` 的样子并标注，不崩。
`area` 统一 **从 0 开始**（决策 D-U05，见《决策记录》）。
`add` 由 UI 侧实现（读 snapshot → 算 → `api.set`），因为 ILB 没有 `add` 接口。

## 验收表（每一条都要点一遍）

| # | 操作 | 期望 |
|---|---|---|
| 1 | 刷新 ST 页面 | 右下角出现浮窗，不遮挡输入框；ILB 悬浮球仍在它上方 |
| 2 | 点浮窗 | 抽屉打开，标题、状态点、计数行可见 |
| 3 | 状态点 | ILB 正常时绿色 + “接口 v1.0”；ILB 被禁用时红色 + 修复提示；版本不符时黄色 |
| 4 | 变量板 | 列出当前聊天所有变量（名 + 值）；数字点一下 +1；空变量显示“—” |
| 5 | 没有变量时 | 显示“这条聊天还没有变量”，并给一个「写入示例变量」按钮（点了才写） |
| 6 | 点「喝药水」 | 生命 -1，界面立刻变；生命到 0 后按钮被 `when` 隐藏 |
| 7 | 在 ILB 面板里改一个变量 | 不用刷新，本界面跟着变（subscribe → 重画） |
| 8 | 关闭抽屉 | 关掉；再点浮窗还能开 |
| 9 | 刷新页面 | 抽屉保持上次的开/关状态 |
| 10 | 切换聊天 | 变量板换成新聊天的变量；布局选择暂时不变（P2 再做字符作用域） |
| 11 | `node tests/run.mjs` | 全绿（plan/validate/store/panel 四组） |

## 已知取舍（P1 不做，记下来别忘）

- 抽屉打开时会盖住 ILB 悬浮球（我们 z-index 4000 > 3900）。这是“右侧抽屉”的代价；P2 会给抽屉加“临时收球”或错位。**先不处理**。
- 布局只在 `localStorage`；`scope: character` 的字段先留空实现，P3 接。
- 没有编辑器，`ui/sample-layout.js` 就是唯一数据源；P2 加粘贴 + 校验。
- 没有 `call` 按钮；`api.callLogic` 已写好但没人调用。
- 手机端只保证不溢出，不专门做竖屏布局。

## 风险

| 风险 | 应对 |
|---|---|
| ST 的扩展加载顺序先于 ILB | 探针 500ms 重试 20 次；期间显示黄点“等待 ILB” |
| 浏览器缓存旧文件 | 文件名带版本号后缀不现实；文档里提醒硬刷新（Ctrl+F5） |
| 样式污染聊天界面 | 全部选择器以 `.dshui-` 开头，根节点 `position: fixed` 单独挂 |
| localStorage 损坏 | 读失败当空库，保留原始字符串在 `dshui.backup.v1` 里一次 |
