## 3. 这一轮修掉的坑

1. **表单里打字不生效**：`renderForm()` 先 `normalizeLayout(state.draft)`，而它会深拷贝，输入回调改的是副本；改为表单直接改 `state.draft`。
2. **页面 id 前向引用**：第一遍收集 id、第二遍校验 `open.page`，否则「先写按钮、后写页面」会被误报。
3. **页内网格**：页面的 `area` 必须按**本页**的 `cols/rows` 校验，不能按顶层；`buildPlan` 返回的 `page` 里带 resolved grid。
4. **探针按钮点错**：ILB 面板也有「导出」按钮；检查脚本的 `clickOwn` 限定在 `.dshui-root` 内，并且优先精确文本。
5. **`validateLayout` 对同一布局反复校验**：`open.page` 需要整份布局的页面表，所以改成「先 normalize 全量 → 再逐页查」。
6. **表单/JSON 切换卡在 JSON（用户反馈）**：切换时现在**先**无条件改页签/显隐（`applyModeUi`），再做解析与重绘；`hidden` 之外再加 `style.display` 兜底；`render()` 包了 try/catch，出错会显示在底栏而不是静默保持旧画面。标题栏加了版本徽标（现在 `v0.3.1`），用于确认页面加载的是哪一版。
7. **表单区太矮（用户反馈）**：编辑态的编辑区改为固定高度（默认 50%），预览区 `flex: 1` + 自身滚动；两者之间加拖动条。顺带踩到 PowerShell `Get-Content/Set-Content` 会把 UTF-8 中文压成 GBK 且加 BOM，`manifest.json` 当场坏掉——改 JSON 一律用 `write`/`edit`，不用 PowerShell 回写。

## 6. 手动验收（在 ST 里点一遍）

1. **Ctrl+Shift+R** 强制刷新（扩展脚本是 ES module，普通刷新可能复用旧模块），右下角 ▦ → 打开；标题栏应显示 `v0.3.1`。
2. 点「编辑」：默认在「表单」，能看到标题、网格、页面下拉、8 个控件块；预览与表单之间有拖动条，往上/下拖改变比例，双击复位。
3. 改标题为「我的面板」→ 往下滚点「＋控件」→「应用」：预览里多一格；状态行显示「布局：我的面板」。
4. 点右边「保存（全局）」→ 刷新页面：下拉框里能选到「我的面板（全局）」。
5. 点「背包」页签 → 看到物品列表；点「← 返回主界面」回到第一页（这是 `open` 动作，不是刷新）。
6. 点「导出」：浏览器下载 `dshui-*.json`；把内容粘进「导入」→「导入这段 JSON」：预览切换，但不保存。
7. 点「编辑 → 管理布局」：能看到自己保存的条目，删除后下拉框里消失。

## 7. 已知边界

- **页面不嵌套、没有返回栈**：`open` 只切到目标页；「返回」是作者自己放一个 `open` 按钮，不自动记住来路。
- **导入只到预览**：这是有意的，防止误粘覆盖当前布局；满意后要再点一次「保存」。
- **失效布局只列不自动删**：删角色卡后，它名下的布局仍在库里且会在「管理布局」里出现（带角色卡名）；自动清理需要扫描全部存档，留到后续。
- **导出不含 avatar**：布局内容与作用域会导出，角色卡头像名不导出，导入方按自己的当前角色卡保存。
- **同一页内 `open` 的 page id 不能重复**；页面 id 缺省按 `page-1…` 生成，作者最好显式写。
